# Dashboard Design

## Who and what for
A dashboard answers a recurring question for a specific person. Name both. "Is the business healthy this week?" for a founder is a different screen from "Which campaign should I pause?" for a marketer.

## Choose metrics
Five to seven at most. For each: the definition, the comparison that gives it meaning (versus last period, versus target), and what someone would do if it moved. Drop any metric nobody would act on.

## Layout
- Top left is read first: put the headline numbers there, each with its change and direction.
- Then trends over time, then breakdowns that explain the trends, then detail tables.
- Group related things; align to a grid; keep filters in one place.

## Charts
- Time: line. Comparing categories: horizontal bars, sorted. Part of a whole: a stacked bar or a single number, rarely a pie. Relationship: scatter.
- Bars start at zero. Label directly instead of using a legend where possible.
- Colour carries meaning: neutral by default, one colour to highlight, red and green only for bad and good - and never as the only signal.
- Titles state the finding or the question, not just the metric name.

## Honesty
Show the date range and when data was last updated. Mark incomplete periods. Use the same scale when charts are meant to be compared.
