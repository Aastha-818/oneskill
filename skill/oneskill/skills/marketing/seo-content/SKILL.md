# Seo Content

## Intent decides everything
For the target query, work out what the searcher wants: to learn, to compare, to buy, or to reach a specific site. Look at what ranks now if you can search - the format that wins (guide, list, tool, product page) is the format to make. Do not write a 2,000-word guide for a query people want a calculator for.

## Brief
- Primary query plus three to six closely related ones that the same page can answer.
- The questions a reader will have, in the order they will have them. These become the headings.
- What this page will offer that the current results do not: original data, a clearer example, a template, real experience.

## On the page
- Title tag under 60 characters with the query near the front; it must also make a person want to click.
- Meta description under 155 characters: the benefit, not a keyword list.
- One H1. Headings that are real questions or answers.
- Answer the main question in the first 100 words, then go deeper.
- Short paragraphs, descriptive link text, images with alt text, a table or list where it helps scanning.
- Link to related pages on the same site and from them back.

## Do not
Stuff keywords, pad for length, or invent statistics and sources. Write for the reader; search engines follow.

Deliver the brief first for approval when the piece is long, then the draft with title tag and meta description.
